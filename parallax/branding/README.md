# Parallax browser branding

`parallax-orbital.svg` is a byte-for-byte copy of the existing orbital Parallax mark from `public/assets/Parallax Mark.svg` in the sibling `~/parallax/marketing` repository. The source is also used by that repository's marketing homepage in `resources/views/home-new.blade.php`. The marketing repository was not modified.

- SHA-256: `fb6317a9dda1267265ad18147173aa60ee14696a18b5dde3221973de8dbb13a5`
- Original viewBox: `0 0 713.34 692.91`
- Preserve the SVG's gradients, blending, transparency, and aspect ratio. Reference it as an image rather than inlining multiple copies with overlapping gradient IDs.
- Application icons are rasterized from this source. Keep this original as the canonical vector asset.

The existing marketing site uses Inter for interface text (`public/assets/site-fonts.css` and `site-chrome.css`). Its home palette includes deep purple `#120020`, `#21043b`, `#35105c`, accent purple `#9b4dff`, pale purple `#d9b8ff`, and warm paper `#f1e5d2` (`public/assets/parallax-home.css`). These are reference colors; the orbital mark retains its original multicolor gradients.

## Reproduce the icons

From the repository root, use Python 3.10+ with native Cairo installed (on Ubuntu, the `libcairo2` package):

```sh
python3 -m venv parallax/.build/branding-venv
parallax/.build/branding-venv/bin/python -m pip install -r parallax/branding/requirements.txt
parallax/.build/branding-venv/bin/python parallax/tools/generate_branding.py --source-root src
parallax/.build/branding-venv/bin/python parallax/tools/generate_branding.py --source-root src --check
```

The generator discovers existing assets in the Chromium checkout rather than assuming dimensions from filenames. This matters for the double-density and wide `product_logo_name_22*.png` canvases. It renders with CairoSVG, centers the complete orbital mark with transparent padding and the original aspect ratio, and encodes outputs with Pillow. The SVG source is hash-verified before every run and copied unchanged to the product SVG resource paths. The former animated Chromium product SVG becomes a static Parallax mark.

The covered existing assets are:

- All `product_logo*.png` beneath `chrome/app/theme/chromium`, `default_100_percent/chromium`, and `default_200_percent/chromium`, including Linux icons and mono/name variants. Name canvases contain the orbital mark; no Chromium wordmark is retained.
- The Linux `product_logo*.xpm` assets. XPM has binary transparency, so its alpha is thresholded at 128 and its colors are deterministically quantized.
- Windows `chromium.ico`, `chromium_doc.ico`, `chromium_pdf.ico`, and `app_list.ico`, preserving each file's existing frame sizes, plus the `win/tiles/*Logo.png` images.
- macOS `app.icns` and the PNGs in `Assets.xcassets`.
- ChromeOS `chrome_app_icon_*.png`.

Private-mode, isolated-app, password-manager, web-store, and PDF content icons keep their semantic artwork. The Windows PDF file-association product icon is branded. `--check` compares every covered file byte-for-byte with a fresh render, reports mismatches, and returns 1 without writing anything. Invalid source layouts, a changed canonical SVG, or missing dependencies return 2. Generation writes only changed files and renders all outputs successfully before beginning writes.

Reproduction is deterministic with the same pinned Python packages and native Cairo version; PNG rendering can differ across native Cairo releases. No network calls, AI generation, credentials, or desktop interaction occur in the generator.

## Initial platform scope

Linux is the initial build target. The macOS precompiled `Assets.car` and layered `AppIcon.icon` artwork require Apple-specific icon compilation and are not regenerated by this tool. macOS distribution must replace/recompile those catalog resources with Apple tooling before release; the generated ICNS and catalog PNGs alone do not establish complete macOS branding. Original Illustrator `.ai` artwork is retained as upstream source material and is not used for generated Parallax icons.

The pinned icon layout was verified against [Chromium revision 5869fe313571d75152b77813cf0a4ee26a4e6df0](https://chromium.googlesource.com/chromium/src/+/5869fe313571d75152b77813cf0a4ee26a4e6df0/chrome/app/theme/chromium/).
